## Features

**TTTrisk** is a high-precision dual-chain risk intelligence skill built specifically for the Bankr ecosystem on Base and Robinhood Chain.  
It delivers transparent, multi-factor risk scoring and actionable protection insights using only real Bankr API data and market sources.

| Capability                        | Description                                                                 | Status      |
|-----------------------------------|-----------------------------------------------------------------------------|-------------|
| **Overall Risk Score (0–100)**    | Transparent weighted multi-factor scoring (Liquidity + Volatility + Fees + Concentration) | Advanced    |
| **Liquidity Health**              | Exact Liquidity / Market Cap ratio with Strong / Moderate / Weak labels     | Real-time   |
| **Volatility Assessment**         | 24h & 7d price swing analysis with clear risk classification                | Dynamic     |
| **Fee Sustainability**            | Trend detection from Bankr `dailyEarnings` array (rising / flat / collapsing) | Advanced    |
| **Concentration Risk**            | Portfolio-level analysis of fee concentration across tokens                 | Intelligent |
| **Approximate Drawdown**          | Recent peak-to-current price insight                                        | Supported   |
| **Position Sizing Suggestion**    | Clear recommended max allocation based on current risk score                | Actionable  |
| **Dual-Chain Support**            | Full risk view for Base + Robinhood Chain (single token or portfolio)       | Complete    |
| **Cross-Skill Integration**       | Seamless handoff to TTTracker, TTTsignal, TTTalert & TTTfolio               | Full        |

## Install

Install directly into your Bankr agent:

```bash
install the skill at https://github.com/TTtmorena/TTTrisk
```

After installation, the skill activates automatically whenever you ask about risk, risk score, liquidity health, volatility, concentration, position size, protection, or **TTTrisk**.
